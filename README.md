# Мои dotfiles

Управляются с помощью [chezmoi](https://www.chezmoi.io/).

## Быстрая установка

Запустите эту команду для развёртывания окружения:

```bash
git clone --depth 1 https://github.com/leerov/dotfiles.git && cd dotfiles && python3 dot_myaddons/python_scripts/install.py
```

После завершения установки перезапустите оболочку.
